Systems Not Configured Correctly

System Problem Impact
Local Node / Next toolchain Native SWC on this workstation is unusable under the current Node 24 runtime, while the project builds correctly under Node 22. Local npm run build cannot complete until the shell/runtime is aligned with the repo's pinned Node version.
Repo runtime version policy This was missing at review time. The repo now pins 22.x, but local and Vercel installs still need to be aligned to that version. Different machines can install unsupported or untested Node versions, which makes build failures harder to isolate.
Vercel deployment verification The project needed multiple README-only commits to force new deploys, which suggests Git integration or deployment selection has not been reliably validated. Vercel may be building stale commits or old failed deployments, which makes debugging misleading.
Deployment runbook hygiene Deployment trigger notes were written into README.md as an operational workaround. The deployment process was relying on ad hoc triggers instead of a stable, verified release flow. Those notes should stay out of the long-term runbook.
